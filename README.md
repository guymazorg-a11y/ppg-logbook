# יומן מנוע – מצנח ממונע

אפליקציה למעקב שעות מנוע, טיסות ותחזוקה (Vittorazi Moster 185), עם גיבוי מלא לאקסל.

- עובדת **בלי אינטרנט** (גם בשדה), כל הנתונים נשמרים בטלפון בלבד.
- ייבוא טיסות מ-**Gaggle**: קובץ IGC/GPX, או ישירות דרך "שיתוף" באנדרואיד.
- זיהוי אוטומטי של זמן הטיסה (מהמראה עד נחיתה) ושל אתר ההמראה לפי מיקום.
- מעקב החלפות ובדיקות תקופתיות לכל חלק, כולל מגבלת זמן קלנדרית ("או אחרי שנה").
- תזכורת לקיפול מצנח רזרבי.
- **גיבוי לאקסל** באותו מבנה של הקובץ המקורי (`Paramotor Flights.xlsx`) עם נוסחאות חיות, וגם ייבוא חזרה ממנו.

## העלאה ל-GitHub Pages (פעם אחת, כ-5 דקות)

1. נכנסים ל-github.com ופותחים חשבון (אם אין).
2. למעלה מימין **+** ← **New repository**. שם: `ppg-logbook`, לבחור **Public** ← **Create repository**.
3. בעמוד שנפתח: **uploading an existing file** ← לגרור לחלון את **כל הקבצים והתיקיות** מהתיקייה הזו
   (`index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.json`, אייקונים, ותיקיית `vendor`) ← **Commit changes**.
   אין צורך להעלות את `README.md` ואת התיקייה `.claude`.
4. **Settings** ← **Pages** ← תחת *Branch* לבחור `main` ו-`/ (root)` ← **Save**.
5. אחרי דקה-שתיים האפליקציה זמינה בכתובת: `https://<שם-המשתמש>.github.io/ppg-logbook/`

> הקוד ציבורי, אבל **הנתונים שלך לא** – הם נשמרים רק בטלפון ובקובץ האקסל שלך.

## התקנה בטלפון (אנדרואיד)

1. לפתוח את הכתובת ב-**Chrome**.
2. תפריט ⋮ ← **התקנת אפליקציה** / **הוספה למסך הבית**.
3. בפתיחה הראשונה: **ייבוא מקובץ אקסל** ← לבחור את `Paramotor Flights.xlsx` (מ-OneDrive או מההורדות).

## שימוש שוטף

- **אחרי טיסה:** ב-Gaggle ← הטיסה ← Export ← **Export IGC** ← שיתוף ← **יומן מנוע**. הטיסה נפתחת עם התאריך, הזמן והאתר מוכנים, נשאר רק "שמור".
  אפשר גם ידנית: כפתור **＋** ← שעות:דקות ← שמור.
- **טיפול:** לשונית תחזוקה ← "רישום טיפול" ← 🔁 לחלק שהוחלף, 🔍 לחלק שנבדק.
- **גיבוי:** אחרי כל טיסה האפליקציה מציעה לשמור אקסל. בחלון השיתוף לבחור **OneDrive** (או Drive) – הקובץ שם הוא הגיבוי.
  האפליקציה מראה למעלה כמה שינויים עוד לא גובו.

## עדכון גרסה

מעלים את הקבצים החדשים לאותו repository (Add file ← Upload files). הטלפון יקבל את העדכון בפתיחה הבאה עם אינטרנט. הנתונים לא נמחקים.

## הפעלה מקומית במחשב

```
python -m http.server 8765
```
ואז לפתוח `http://localhost:8765`. (אפשר גם בלי שרת, בלחיצה כפולה על `index.html`, אבל אז אין עבודה offline.)
במחשב עם Chrome/Edge אפשר בלשונית "גיבוי" ← **קשר קובץ** לקשר קובץ אקסל בתיקיית OneDrive, והאפליקציה תכתוב אליו אוטומטית אחרי כל שינוי.
